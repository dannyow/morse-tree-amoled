Morse Tree

A Morse code trainer for the Waveshare ESP32-C6-Touch-AMOLED-2.16. This page flashes the latest release onto the module straight from the browser.

  1. Use desktop Chrome or Edge. Safari and Firefox cannot talk to a serial port.
  2. Connect the module with a USB-C cable that carries data.
  3. Press Install, pick the module's serial port and confirm.
  4. When it finishes, unplug the module and plug it back in.
This browser cannot flash devices. Use desktop Chrome or Edge. Flashing needs a secure (https) page.

If the port does not connect, hold BOOT while you plug the module in and try again. The install replaces whatever the module ran before.

Source, manual install and how to build it: github.com/dannyow/morse-tree-amoled
