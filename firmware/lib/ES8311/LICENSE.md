# Licence for this driver

`es8311.c`, `es8311.h`, `es8311_reg.h` are Espressif Systems' ES8311 codec driver,
lifted unmodified from `esp-adf`/`esp-idf`-adjacent examples (via the
`claude-desktop-buddy-esp32` board bring-up, https://github.com/vthinkxie/claude-desktop-buddy-esp32) as a PlatformIO local library so
`firmware/platform/hw/audio.cpp` can find `es8311.h`.
